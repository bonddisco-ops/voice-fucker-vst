# VOICE FUCKER

Dirty, brutal robot-vocal vocoder by **Primal Rage Lab**. VST3 / AU / Standalone for Windows and macOS.

Put it on a vocal track and it turns the voice into a crunchy, wide robot:

- **Carrier**: Saw, Square, Supersaw, Noise, Sidechain or Synth + Sidechain. Pitch from **MIDI** (chords up to 8 notes), **Auto** (follows the melody of the voice) or **Fixed** (one note).
- **Vocoder**: 4 to 100 bands, Formant shift ±12 st, Attack / Release, Sibilance (keeps s/sh/t readable), Gate.
- **Harmonize**: −24, −12, −7, −5, −3, +3, +5, +7, +12 voices, each with its own fader. Scale-aware thirds, fourths and fifths; Alternate / Fan / Spectral panning with Spread.
- **Dirt**: Tube / Hard / Fold. Drive (carrier), Crunch (per-band saturation), Destroy (bitcrush + downsample).
- **Width**: Spectral (bands split left/right, mono-safe), Haas, Chorus; Mono bass.
- **Mix** with Auto gain, **Clip** Soft / Hard with Ceiling, In / Out meters.
- Bulging CRT screen with Wave and Spectrum views, presets, resizable window.

## Download

Every push to `main` builds the plugin on GitHub Actions. Grab the zip for your system from the
**Releases → latest** page (or from the Actions run artifacts). Install steps are in `INSTALL.txt` inside the zip.
