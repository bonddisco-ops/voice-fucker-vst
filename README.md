# VOICE FUCKER

Dirty, brutal robot-vocal vocoder by **Primal Rage Lab**. Version 2.0. VST3 / AU / Standalone for Windows and macOS.

Put it on a vocal track and it turns the voice into a crunchy, wide robot:

- **Carrier**: Saw, Square, Supersaw, Noise, Sidechain or Synth + Sidechain. Pitch from **MIDI** (chords up to 8 notes), **Auto** (follows the melody of the voice) or **Fixed** (one note).
- **Vocoder**: 4 to 100 bands, Formant shift ±12 st, Attack / Release, Sibilance (keeps s/sh/t readable), Gate.
- **Harmonize**: −24, −12, −7, −5, −3, +3, +5, +7, +12 voices, each with its own fader and stereo dot. Root + 23 scales. Manual / Spectral panning with Spread. With the vocoder off it pitch-shifts the voice itself.
- **Dirt**: Soft / Tape / Tube / Fuzz / Hard / Fold. Drive (carrier), Crunch (per-band saturation), Destroy (bitcrush + downsample).
- **Comp**: OTT or Glue.
- **Pre EQ** (only what feeds the effect) and **Post EQ** (effect only) with a draggable curve.
- **Width**: Spectral (bands split left/right, mono-safe), Haas, Chorus; Mono bass.
- **Mix** with Auto gain, **Clip** Soft / Hard with Ceiling, In / Out meters.
- Bulging CRT screen with Wave, Spectrum and EQ views, five themes, hints and a tour in English and Russian, presets, resizable window.

## Download

Every push to `main` builds the plugin on GitHub Actions. Grab the zip for your system from the
**Releases → latest** page (or from the Actions run artifacts). Install steps are in `HOW TO INSTALL.txt` inside the zip; the zip also contains a one-click installer.
